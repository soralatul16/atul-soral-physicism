8.4 · Many slits, sharp bright lines

Diffraction Grating

A diffraction grating is a plate ruled with hundreds of equally spaced slits per millimetre. Light from every slit interferes, giving very sharp, bright maxima at the angles where d sinθ = nλ. That makes it the most accurate way to measure the wavelength of light.

AS Level · Core

A laser shines normally (at 90°) onto the grating. Bright maxima appear only at the angles where light from neighbouring slits arrives in phase. Change the wavelength, the number of lines per millimetre and the screen distance, and watch every order move.

Top view — laser, grating and screen

Each bright spot is one order, n. The straight-through spot is n = 0. Orders whose rays miss the screen still exist; the screen is just not wide enough to catch them.

Why only these angles?

Light leaving two neighbouring slits at angle θ has a path difference of d sinθ. When that path difference is a whole number of wavelengths, the waves from every slit arrive in phase and reinforce: a bright maximum.

With hundreds of slits, even a tiny change of angle puts the waves out of step, so they cancel. That is why grating maxima are much sharper and brighter than double-slit fringes.

Method: measuring λ with a grating

  1. Shine the laser normally onto the grating, with a screen a measured distance D away (metre rule).
  2. Mark the central maximum and the first-order maxima on both sides.
  3. Measure the distance between the two first-order maxima and halve it to get x.
  4. Find the angle: tanθ = x / D.
  5. Find the line spacing: d = 1 / N, with N in lines per metre.
  6. Calculate λ = d sinθ / n. Repeat with the second order and take a mean.

Grating angles are large, so do not use the small-angle shortcut λ = ax/D from Young’s slits. Always find θ first.

Practice · Exam-style
A laser beam is directed normally at a diffraction grating that has 400 lines per mm. The second-order maxima are observed at an angle of 30.0° to the straight-through direction.
(a) Calculate the separation d of the lines of the grating. [1]
N = 400 mm⁻¹ = 4.00 × 10⁵ m⁻¹, so d = 1 / N = 2.50 × 10⁻⁶ m.
(b) Calculate the wavelength of the light. [2]
d sinθ = nλ ⇒ λ = (2.50 × 10⁻⁶ × sin 30.0°) / 2 = 6.25 × 10⁻⁷ m (625 nm).
(c) Determine the total number of maxima that can be observed. [2]
d / λ = 2.50 × 10⁻⁶ / 6.25 × 10⁻⁷ = 4.0. The order n = 4 would need sinθ = 1 (θ = 90°), along the grating, so it cannot be seen. Highest order = 3, so the number of maxima = 3 + 3 + 1 (central) = 7.
✓ Nice — d from N, λ from d sinθ = nλ, and nmax rounded down: the three classic grating marks.
AS Level · Core

Almost every grating question uses one equation, d sinθ = nλ. Marks are lost on units (lines per mm to lines per m), on using the small-angle approximation, and on forgetting that sinθ cannot exceed 1.

Worked Example 1
Light of wavelength 600 nm is incident normally on a grating with 500 lines per mm. Calculate (a) the line spacing, (b) the angle of the second-order maximum and (c) the total number of maxima seen.

(a) N = 500 mm⁻¹ = 5.00 × 10⁵ m⁻¹

d = 1 / N = 1 / 5.00 × 10⁵ = 2.00 × 10⁻⁶ m

(b) For n = 2:

sinθ = nλ / d = (2 × 600 × 10⁻⁹) / 2.00 × 10⁻⁶ = 0.600 ⇒ θ = 36.9°

(c) The largest possible value of sinθ is 1:

n ≤ d / λ = 2.00 × 10⁻⁶ / 600 × 10⁻⁹ = 3.33 ⇒ nmax = 3
Total maxima: three on each side plus the central maximum = 7. Always round nmax down.
Worked Example 2
A grating with 300 lines per mm is placed 1.50 m from a screen. The distance between the two first-order maxima on the screen is 0.570 m. Calculate the wavelength of the light.

Distance from the centre to one first-order maximum:

x = 0.570 / 2 = 0.285 m

Find the angle first (it is too large for a small-angle approximation to be safe):

tanθ = x / D = 0.285 / 1.50 = 0.190 ⇒ θ = 10.76°
d = 1 / 3.00 × 10⁵ = 3.33 × 10⁻⁶ m
λ = d sinθ / n = 3.33 × 10⁻⁶ × sin 10.76° / 1 = 6.22 × 10⁻⁷ m (622 nm)
Mark points: halve the separation; tanθ = x / D; d from N in m⁻¹; λ = d sinθ / n with the correct order.
Worked Example 3
White light (400 nm to 700 nm) falls normally on a grating with 400 lines per mm. Show that the second-order and third-order spectra overlap, but the first and second do not.
d = 1 / 4.00 × 10⁵ = 2.50 × 10⁻⁶ m

Each spectrum runs from violet (smallest angle) to red (largest angle).

1st order red: sinθ = 700 × 10⁻⁹ / 2.50 × 10⁻⁶ = 0.280 ⇒ θ = 16.3°
2nd order violet: sinθ = 2 × 400 × 10⁻⁹ / 2.50 × 10⁻⁶ = 0.320 ⇒ θ = 18.7°

18.7° > 16.3°, so the second-order spectrum starts after the first ends: no overlap.

2nd order red: sinθ = 2 × 700 × 10⁻⁹ / 2.50 × 10⁻⁶ = 0.560 ⇒ θ = 34.1°
3rd order violet: sinθ = 3 × 400 × 10⁻⁹ / 2.50 × 10⁻⁶ = 0.480 ⇒ θ = 28.7°
Conclusion: the third-order spectrum begins at 28.7°, before the second order ends at 34.1°, so they overlap. Try it on page 1: choose White light and 400 lines per mm.
AS Level · Core

The commonest ways candidates lose diffraction grating marks. Fix these now.

"d is the number of lines per mm."
d is the spacing between lines: d = 1 / N.

Convert N to lines per metre first: 300 lines per mm = 3.00 × 10⁵ m⁻¹, so d = 3.33 × 10⁻⁶ m. Using N directly gives a nonsense answer.

"Use λ = ax / D, like Young’s double slit."
Use d sinθ = nλ, finding θ from tanθ = x / D.

λ = ax / D relies on small angles. Grating angles are often 10° to 60°, where sinθ and tanθ are very different.

"You can see as many orders as you like."
sinθ can never be bigger than 1, so n ≤ d / λ.

Round d / λ down. If d / λ is a whole number exactly, that order is at 90° and is not seen either.

"With white light, the central maximum is a spectrum."
The central maximum (n = 0) is white.

At θ = 0 the path difference is zero for every wavelength, so all colours arrive together. Spectra appear only in the orders n = 1, 2, 3…

"Violet is diffracted most, like in a prism."
Red is diffracted most by a grating.

sinθ = nλ / d, so the longest wavelength (red) has the biggest angle. In each order violet is nearest the centre, the opposite of a prism.

"More lines per mm squeezes the maxima closer together."
More lines per mm spreads them further apart.

More lines means smaller d, so sinθ = nλ / d is larger. The maxima spread out, become sharper, and fewer orders fit before 90°.
