Explore, then answer: drag each slider on its own and watch the drift-speed readout. The drift never leaves the 10⁻⁵ range — it's always a crawl.
Why more carriers means SLOWER drift (read if stuck on Q6) Current is how many charge-carriers cross a line each second. If you want the same current but now have far more electrons available (bigger n), each one only needs to shuffle along slowly and you'll still get enough across per second. With few electrons, each has to hurry to keep the count up. Like a corridor delivering 100 people/second: if it's packed, everyone shuffles slowly; if it's nearly empty, the few must sprint. Same flow, opposite speeds. That's why n sits in the bottom of v_d = I/(nAq).
What the sim shows Bigger I speeds the electrons up; bigger A or bigger n lets them go slower for the same current. That's exactly v_d = I/(nAq) — which you'll build next in Q8.

Explorer 4 break the model

Metal vs semiconductor: heat them both

Your model says "hotter = more collisions = more resistance." Test it. Switch between a metal and a semiconductor, then heat each one and watch the resistance graph. One obeys your model. One does the opposite.

Question: the metal's resistance rises with heat (your model works). The semiconductor's falls — your model predicts the opposite! What is heat doing to the semiconductor that your "collisions" idea ignored? (Hint: the number of carriers, n.)
The fix Resistance depends on collisions and on how many carriers there are. Heating a metal barely changes n, so more collisions win → R rises. Heating silicon frees a flood of new carriers (n shoots up), which beats the extra collisions → R falls. Your model wasn't wrong — it was missing n.
